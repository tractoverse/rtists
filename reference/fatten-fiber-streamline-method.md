# [`fatten()`](https://tractoverse.github.io/rtists/reference/fatten.md) method for `fiber::streamline` objects

Assigns a single
[fiber::streamline](https://tractoverse.github.io/fiber/reference/streamline.html)
a visible tube radius (the visibility floor) so
[`plot3d()`](https://tractoverse.github.io/rtists/reference/plot3d.md)
draws it as a real 3D tube. A lone fibre has no other streamlines to
collide with, so there is nothing to prune.

## Arguments

- x:

  A
  [fiber::streamline](https://tractoverse.github.io/fiber/reference/streamline.html),
  [fiber::bundle](https://tractoverse.github.io/fiber/reference/bundle.html),
  or
  [fiber::bundle_set](https://tractoverse.github.io/fiber/reference/bundle_set.html).

- visibility:

  Numeric. The smallest tube radius considered visible to the naked eye.
  `NULL` (default) derives it from the streamlines' sampling density
  (the median intra-streamline step); a positive number overrides the
  floor.

- ...:

  Reserved for future arguments.

## Value

A
[fiber::streamline](https://tractoverse.github.io/fiber/reference/streamline.html)
carrying a per-streamline `radius`.

## See also

[`fatten()`](https://tractoverse.github.io/rtists/reference/fatten.md)

## Examples

``` r
library(fiber)

# A smooth fibre curving through 3-D space, sampled at a 0.1 mm step.
t   <- seq(0, 4 * pi, length.out = 200)
sl <- streamline(cbind(
  X = seq_len(200) * 0.1,
  Y = 0.5 * sin(t),
  Z = 0.5 * cos(t)
))

# fatten() attaches a per-streamline radius; plot3d() then draws a tube.
fattened <- fatten(sl)
fattened@streamline_data$radius
#> [1] 0.1048645
plot3d(fattened)
```
