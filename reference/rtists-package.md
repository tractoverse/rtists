# rtists: R for Tissue Integrity Superimposed on Tractography Streamlines

Provides interactive 3-D visualisation of tractography streamlines,
bundles, and bundle sets defined in the 'fiber' package. Aesthetics such
as line colour can be mapped to per-point, per-streamline, or per-bundle
metadata, or derived from the local fibre orientation. See Dell'Acqua,
F., Descoteaux, M. and Leemans, A. (2024) "Handbook of Diffusion MR
Tractography"
[doi:10.1016/C2018-0-02520-7](https://doi.org/10.1016/C2018-0-02520-7)
for more about the mathematical and computational underpinnings of
diffusion MRI tractography.
